# Pixel Art Editor

ブラウザだけで使える、単一HTMLファイルのピクセルアートエディターです。インストールやビルドは不要で、`pixel_art_editor.html` を開くだけでドット絵の作成、画像の読み込み、レイヤー編集、PNG保存ができます。

## 特徴

- ペン、消しゴム、塗りつぶし、スポイト、なげわ選択
- 丸、四角、テキストの描画
- ブラシサイズ変更
- 図形の塗り/線の切り替え
- 横書き/縦書きテキスト
- 美咲ゴシック、美咲明朝フォント対応
- カラーピッカー、HEX入力、固定パレット
- レイヤーの追加、複製、並べ替え、表示切替、削除、名前変更
- 選択範囲のコピー、左右反転、90度回転、矢印キー移動
- PNG/JPEG/WebP画像のインポート
- PNG形式での書き出し
- 32x32、64x64、128x128、任意サイズのキャンバス設定

## 使い方

1. `pixel_art_editor.html` をブラウザで開きます。
2. 左側のツールから描画方法を選びます。
3. 中央のキャンバスでピクセルを編集します。
4. 必要に応じて右側のレイヤーやキャンバス設定を調整します。
5. 右上または右側の「PNG保存」から画像を書き出します。

## 起動方法

ローカルファイルとしてそのまま開けます。

```text
pixel_art_editor.html
```

美咲フォントは `fonts/` フォルダに同梱しているため、オフラインでもテキスト描画に使用できます。

## iPhoneで使う

PC内の `pixel_art_editor.html` は、iPhoneから直接開けません。PCでローカルWebサーバーを起動し、iPhoneのSafariからURLでアクセスしてください。

### 1. PCでサーバーを起動する

PowerShellでこのフォルダを開き、次のコマンドを実行します。

```powershell
.\start_iphone_server.ps1
```

PowerShellの実行ポリシーで止まる場合は、`start_iphone_server.bat` をダブルクリックしてください。

表示されたURLを確認します。

```text
http://PCのIPアドレス:4173/
```

### 2. iPhoneで開く

PCとiPhoneを同じネットワークに接続し、iPhoneのSafariのアドレス欄に表示されたURLを直接入力します。PCはイーサネット接続でも問題ありません。iPhoneは同じルーターのWi-Fiに接続してください。

GoogleアプリやGoogle検索欄ではなく、Safariアプリの上部にあるアドレス欄に入力してください。Google検索結果が表示される場合は、URLを検索してしまっています。

### 3. ホーム画面に追加する

Safariでアプリを開いたあと、共有ボタンから「ホーム画面に追加」を選ぶと、アプリ風に起動できます。

### iPhone向け表示

- キャンバスが先に表示され、すぐ描き始められます。
- インポート/PNG保存ボタンは画面下部に固定表示されます。
- 描画ツールは横スクロールできる大きめのボタンになります。
- ホーム画面に追加すると、アプリ風に起動できます。

## 主な操作

- `Ctrl + Z` / `Command + Z`: 元に戻す
- `Shift` を押しながらペン/消しゴム: 直線描画
- `Shift` を押しながら図形描画: 正方形や正円に近い形で描画
- 選択範囲がある状態で矢印キー: 選択範囲を1マス移動
- レイヤー名をダブルクリック: レイヤー名を変更

## インポート

「インポート」からPNG、JPEG、WebP画像を読み込めます。読み込んだ画像はキャンバスサイズに合わせてピクセル化され、最大128x128の範囲に収まるように処理されます。

## PNG保存

「PNG保存」を押すと保存前の確認ダイアログが表示されます。保存される画像は表示中のレイヤーを合成したPNGです。ファイル名は右側の入力欄で変更できます。

## 対応環境

Canvas APIに対応したモダンブラウザで動作します。

- Google Chrome
- Microsoft Edge
- Firefox
- Safari

## 開発メモ

このアプリはHTML、CSS、JavaScriptを1ファイルにまとめた構成です。ビルドツールやパッケージマネージャーは使用していません。

## GitHub Pagesで公開する

GitHubにアップロードしたあと、リポジトリの `Settings` > `Pages` で公開元を `main` ブランチの `/root` に設定すると、ブラウザからアクセスできるURLが発行されます。

`index.html` から `pixel_art_editor.html` に自動で移動するため、公開URLはリポジトリのトップURLだけで開けます。
